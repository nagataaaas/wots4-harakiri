# Harakiri（一撃死）

侍道4 Steam版向けの一撃死モードです。プレイヤーとNPCの攻撃ダメージを非常に大きくし、斬撃では死亡、峰打ちでは活力0とゲーム本来の気絶処理を発生させます。

現在は開発版です。実ゲームでの動作は要ゲーム内確認です。イベント中の特殊な無敵状態や通常のダメージ処理を通らない攻撃は対象外になる場合があります。

ModLoaderとともに `mods/harakiri/mod.dll` と `config.ini` を配置してください。難易度選択の末尾に「一撃死」（英語では「Harakiri」）を追加します。選択すると有効になり、既存の難易度を選ぶと無効になります。「難しい」「超難しい」の解放条件はそのままです。

既存の「超難しい」は英語ではVeryHard、新しい「一撃死」はHarakiriと表示します。

一撃死以外はすべて「超難しい」と同じです。敵の強さ、評価・報酬、武器生成などには超難しいの値を渡します。Mod内とセーブでは独立した難易度 `Harakiri = 4` を使い、ゲームの通常処理では `超難しい = 3` に変換します。既存の「普通」や「超難しい」を選んだ場合は、一撃死にはなりません。

セーブ・ロードと死亡後のリトライでもHarakiriを復元し、セーブ一覧には「一撃死 / Harakiri」を表示します。Harakiriで保存したデータの読み込みには、このModが必要です。`config.ini` の `[harakiri] enabled=0` はMod全体を無効にします。既定値は1で、これだけで既存の難易度が一撃死になることはありません。

同心の捕縛のけりは、体力へのダメージはゲーム本来のままで、1発で活力が尽きて捕縛されます。ゲームが本来ダメージを与えない攻撃や、体力の下限を決めている場面では死なずに、ゲーム本来の流れになります。

拷問には戦闘とは別のゲージ計算があり、このModでは拷問のダメージを変更しません。

ゲームファイルは書き換えず、起動時に対応する版とコードを照合してメモリ上にフックします。

ビルドはModLoaderリポジトリで `cmake -S . -B build -A Win32`、`cmake --build build --config Release` を実行します。出力は `build/game/mods/harakiri/mod.dll` です。単体ビルドでは `-DWOTS4_SDK_DIR=<ModLoaderのパス>` を指定してください。

テストは `ctest --test-dir build -C Release -R harakiri --output-on-failure`。ゲームを起動しません。
