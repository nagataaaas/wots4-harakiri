# Harakiri（一撃死）

[English](README.en.md) | [更新履歴](CHANGELOG.md)

> [!NOTE]
> この Mod は [Steam 版『侍道4』](https://store.steampowered.com/app/312780/4/?l=japanese)専用です。

難易度「一撃死」を追加します。主人公も NPC も、攻撃を1回受けるだけで倒れます。

## 機能

### 難易度「一撃死」

- 難易度の選択の最後に「一撃死」（英語では「Harakiri」）が加わります。「難しい」「超難しい」の解放条件は変わりません。
- 斬撃を受けると死に、峰打ちを受けると活力が尽きて気絶します。主人公にも NPC にも同じように働きます。
- 同心の捕縛のけりは、体力へのダメージはそのままで、1発で活力が尽きて捕縛されます。
- 一撃死になること以外は「超難しい」と同じです（敵の強さ、評価・報酬、武器の生成など）。

### セーブ

- セーブの一覧には「一撃死」（英語では「Harakiri」）と表示します。
- 一撃死で保存したセーブを読み込むには、この Mod が必要です。

### 一撃死にならない場面

- もともとダメージを与えない攻撃や、体力の下限が決まっている場面では死なず、ゲーム本来の流れになります。
- イベント中の特別な無敵や、通常とは別の仕組みでダメージを与える攻撃では、一撃死にならないことがあります。
- 拷問のダメージは変えません。

### ゲーム内で確認した動作

次の場面は、ゲーム内で問題なくプレイできることを確認しています。

- 戦闘
  - 体力・活力の減り方
  - DLC の、体力に特殊な動きをする NPC
- 同心・岡っ引きなどによる捕縛
- 拷問
- 夜這い

## インストール

### 自動インストール（推奨）

1. ゲームを終了してください。
2. [WayOfTheSamurai4ModInstaller.exe](https://github.com/nagataaaas/wots4-mods/releases/latest/download/WayOfTheSamurai4ModInstaller.exe) をダウンロードして実行してください。
   - 「Windows によって PC が保護されました」と出たら、「詳細情報」→「実行」を押してください。
   - 管理者として実行してよいかの確認が出たら、「はい」を押してください（ゲームのフォルダに書き込むためです）。
3. 画面の案内に沿って進め、Mod の一覧で `harakiri` を選んでください。↑↓ で移動し、Space で選び、Enter で確定します。

ModLoader も一緒に入ります。更新も同じ手順でできます。設定（`config.ini`）は引き継がれます。

## アンインストール

1. ゲームを終了してください。
2. `{侍道4インストールフォルダ}/mods/harakiri/` フォルダを削除してください。中の設定（`config.ini`）も消えます。

> [!WARNING]
> 一撃死で保存したセーブは、この Mod を削除すると読み込めなくなります。

## 設定

ゲームを終了し、`{侍道4インストールフォルダ}/mods/harakiri/config.ini` を編集してください。保存してからゲームを起動すると、設定が反映されます。

| セクション | 項目      | 既定値 | 説明                                                                                                                          |
| ---------- | --------- | ------ | ----------------------------------------------------------------------------------------------------------------------------- |
| `harakiri` | `enabled` | `1`    | `0` にすると Mod 全体を無効にし、難易度「一撃死」も出なくなります。`1` にしても、ほかの難易度が一撃死になることはありません。 |

## ビルド

> [!NOTE]
> この Mod を利用するだけであれば不要です。修正や開発を行いたい場合にのみ参照してください。

ふつうは [wots4-mods](https://github.com/nagataaaas/wots4-mods) の中でビルドします。この Mod だけをビルドするときは、`-DWOTS4_SDK_DIR=<wots4-mods のパス>` を付けて CMake を実行します。
